2. SPIKE Hubへ接続

DFUモードでの接続手順
  1. Hubの電源を切り、USBケーブルを抜きます。
  2. Bluetoothボタンを押したままUSBケーブルを接続します。
  3. ボタンが赤・緑・青に繰り返し点滅したら離します。
  4. 「Hubに接続」を押してDFUモードのHubを選択します。

Windows: 初回のみWinUSBドライバーの割り当てが必要になる場合があります。
